# cars_price_prediction
training a machine learning model to predict the price of a car based on available features
Датасет - https://www.kaggle.com/datasets/taeefnajib/used-car-price-prediction-dataset/data
Данный датасет был выбран в качестве пет-проекта для решения задачи регрессии: Важным для меня было предсказание цены авто на основе имеющихся данных и признаков
В рамках данного проекта были проведены:
1)Исследовательский анализ данных (EDA) и визуализация распределений.
2)Предобработка пропусков и кодирование категориальных признаков.
3)Сравнение трех классов моделей: линейная регрессия с регуляризацией (Ridge), ансамбль случайного леса и градиентный бустинг (XGBoost).
4)Подбор гиперпараметров через GridSearchCV и оценка качества по MAE и R²
Сформированные гипотезы:
1)Гипотеза 1: Модель в целом будет иметь больший R^2 на логнормированных данных чем при переводе из логарифма обратно в доллары целевой переменной
Гипотеза подтвердилась частично (R^2(not_log) = 0.57 vs R^2(log) = 0.73), (MAE(not_log) = 12881 vs MAE(log) = 30320)
2)Гипотеза 2: После проведения feature engineering и другого кодирования различных признаков - R^2 станет больше, MAE уменьшится и MAPE тоже уменьшится
Гипотеза подтвердилась (R^2 = 0.57 vs R^2 = 0.82), (MAE = 12881 vs MAE = 8858)
3)Гипотеза 3: За счёт дополнительного future engineering метрики улучшатся, R^2 будет выше, MAE и MAPE будут ниже
Гипотеза не подтвердилась (R^2 = 0.82 vs R^2 = 0.69), (MAE = 8858 vs MAE = 13509)
4)Гипотеза 4: При использовании кросс-валидации, модели будут показывать либо такие же показатели по метрикам, либо метрики будут выше, разбиение буду делать через KFold, проверю на RandomForestRegressor, затем на всех трёх
Подтвердилась частично (R^2 = 0.82 vs R^2 = 0.82), (MAE = 8858 vs MAE = 39417)
5)Гипотеза 5: Гипотеза 5: Модель XGBoostRegressor покажет лучшие показатели по метрикам чем две другие R^2 и MAE XGBoost < R^2 и MAE RandomForest < R^2 и MAE Ridge
Гипотеза подтвердилась . Ridge-регрессия (базовая модель): MAE: 12 943.81 (± 550.86), MAPE: 0.29 (± 0.01), R²: 0.79; RandomForestRegressor:  MAE: 10 243.82, MAPE: 0.25, R²: 0.85 ; XGBoostRegressor (лучшая модель): MAE: 9 963.19, MAPE: 0.24, R²: 0.86 
Лучший результат достигнут с помощью XGBoost:MAE снижен на 23% по сравнению с Ridge (с 12 944 до 9 963), Модель показывает наименьшую вариативность ошибки (std = 233.31), что свидетельствует о ее устойчивости, Коэффициент детерминации R² = 0.86, что означает, что модель объясняет 86% изменчивости цен на автомобили
